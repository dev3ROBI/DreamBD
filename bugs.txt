NEW BUGS & SECURITY VULNERABILITIES (Found May 23, 2026)
=======================================================================

45. [index.php:86] HIGH - Reflected XSS via $_COOKIE['dreambd-theme'].
    The theme cookie value is reflected directly into the <html> class and 
    data-theme attributes without sanitization.

46. [handlers/p2p_handler.php] CRITICAL - Missing Escrow in P2P Trading.
    Coins are only deducted from the seller when they click "Release Coins".
    There is no escrow mechanism to hold coins when a trade is opened, 
    allowing for double-spending or merchant loss if the seller spends 
    their coins before releasing them.

47. [handlers/p2p_handler.php:260] MEDIUM - CSRF on state-modifying GET request.
    The 'get_p2p_payment_settings' action inserts default rows into the 
    database but does not validate CSRF tokens for GET requests.

48. [includes/functions.php] MEDIUM - Transaction Early Returns without Rollback.
    Several functions (createAgentAccount, deductPrizeFromAgent, etc.) have 
    return statements inside a beginTransaction() block that execute BEFORE 
    calling rollBack(). This can leave database transactions hanging.

49. [includes/functions.php:1681] MINOR - Fragile LIMIT parameter binding.
    getAgentTransactions() and others pass $limit in the execute() array. 
    This can fail on some PDO configurations if $limit is not explicitly 
    bound as an integer.

50. [admin/user-manager.php] MINOR - Non-functional placeholders.
    Delete User, Export, and Load More features are currently just "coming soon" 
    alerts and do not perform any actual actions.

36. [includes/functions.php:1550] STILL PRESENT - TOCTOU in registerForTournament.
    The check for max_teams is done outside the database transaction.

40. [handlers/p2p_handler.php:120] STILL PRESENT - Potential Deadlock.
    confirm_p2p_received() locks the seller and buyer in an inconsistent 
    order relative to other potential trades, risking deadlocks in 
    concurrent p2p transactions between the same parties.
